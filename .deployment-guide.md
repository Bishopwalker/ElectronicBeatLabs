# EBL Deployment Guide - Simple & Fast

## 🚀 Quick Deploy (Recommended)

### Frontend - Vercel (FREE)

1. **Install Vercel CLI** (already done ✅)
   ```bash
   npm install -g vercel
   ```

2. **Deploy Frontend**
   ```bash
   # Login to Vercel (first time only)
   vercel login

   # Deploy
   vercel --prod
   ```

3. **Set Environment Variables** (in Vercel dashboard)
   - `VITE_API_URL` → Your backend URL (from step below)
   - `VITE_WS_URL` → Your WebSocket URL (from step below)

---

### Backend - Railway.app (FREE tier available)

1. **Install Railway CLI**
   ```bash
   npm install -g @railway/cli
   # or
   curl -fsSL https://railway.app/install.sh | sh
   ```

2. **Login & Deploy**
   ```bash
   railway login
   railway init
   railway up
   ```

3. **Set Environment Variables** (in Railway dashboard or CLI)
   ```bash
   railway variables set DATABASE_URL=sqlite:///./ebl.db
   railway variables set JWT_SECRET_KEY=your-secret-key-here
   railway variables set ENVIRONMENT=production
   ```

4. **Get Backend URL**
   ```bash
   railway domain
   # Copy this URL for frontend VITE_API_URL
   ```

---

## Alternative: Render.com Backend

If you prefer Render:

1. **Connect GitHub repo** to Render.com
2. **Create New Web Service**
3. **Use `render.yaml`** (already configured in project)
4. **Set environment variables** in Render dashboard

## 📋 Environment Variables Checklist

### Backend (Railway/Render)
- ✅ `DATABASE_URL` - SQLite path or PostgreSQL URL
- ✅ `JWT_SECRET_KEY` - Generate with `openssl rand -hex 32`
- ✅ `ENVIRONMENT` - Set to `production`
- ⚠️ `STRIPE_SECRET_KEY` - Your Stripe secret key (optional for now)
- ⚠️ `KEYCLOAK_SERVER_URL` - Your Keycloak URL (optional for now)

### Frontend (Vercel)
- ✅ `VITE_API_URL` - Backend URL from Railway/Render
- ✅ `VITE_WS_URL` - WebSocket URL (usually same as API URL with ws://)

## 🐛 Troubleshooting

### PyAudio Installation Fails on Render
- Use Railway instead (better system dependency support)
- Or remove PyAudio if not using local audio generation

### CORS Errors
- Add Vercel frontend URL to backend CORS allowed origins
- Check `backend/main.py` CORS configuration

### WebSocket Connection Fails
- Ensure `VITE_WS_URL` uses correct protocol (ws:// or wss://)
- Check Railway/Render supports WebSocket (both do!)
