# 🚀 UNIVERSAL CONTEXT ENGINEERING TEMPLATE
**Copy this entire `.claude/` folder structure to any new project**

## 📁 Required File Structure
```
.claude/
├── CLAUDE.md              # Main development standards (this file)
├── INDEX.md               # Navigation guide  
├── INITIAL.md             # Technical specifications
├── VALIDATION.md          # Quality checklists
├── INFRASTRUCTURE.md      # Environment & deployment
├── RAG_CONTEXT.md        # Code discovery patterns
└── PROJECT_CONFIG.md     # Project-specific variables
```

## 🔧 Setup Instructions

### Step 1: Copy Template
1. Copy entire `.claude/` folder to new project root
2. Rename `UNIVERSAL_CONTEXT_TEMPLATE.md` to `TEMPLATE_INSTRUCTIONS.md` 

### Step 2: Configure Project Specifics
Edit `PROJECT_CONFIG.md` with your project details:

```markdown
# PROJECT CONFIGURATION
**Language**: [Python/JavaScript/TypeScript/Go/Rust/etc]
**Framework**: [React/FastAPI/Django/Express/Next.js/etc] 
**Package Manager**: [npm/yarn/pip/cargo/go mod/etc]
**Testing Framework**: [Jest/Pytest/Mocha/etc]
**Linting**: [ESLint/Pylint/Flake8/etc]
**Formatting**: [Prettier/Black/gofmt/etc]
**CI/CD Platform**: [GitHub Actions/GitLab CI/Jenkins/etc]
**Deployment**: [AWS/Vercel/Railway/Heroku/Docker/etc]
**Database**: [PostgreSQL/MySQL/MongoDB/Redis/etc]
**Main Ports**: [Frontend: 3000, Backend: 8000, etc]
```

### Step 3: Update File References  
- Update all `CLAUDE.md` references to match your project structure
- Update `PLANNING.md` path in INDEX.md if different
- Update `TASK.md` path in INDEX.md if different

### Step 4: Ready to Rock!
Your context engineering is now setup universally 🎯
