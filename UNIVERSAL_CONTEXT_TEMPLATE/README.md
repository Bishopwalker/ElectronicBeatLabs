# 🚀 UNIVERSAL CONTEXT ENGINEERING TEMPLATE

**Complete context engineering package for any project - just copy and configure!**

## 📦 What's Included

### Template Files:
- `TEMPLATE_CLAUDE.md` - Universal development standards with communication style
- `TEMPLATE_PROJECT_CONFIG.md` - Fill out your tech stack here  
- `TEMPLATE_INDEX.md` - Navigation guide
- `TEMPLATE_INITIAL.md` - Technical documentation links
- `TEMPLATE_VALIDATION.md` - Quality assurance checklists
- `TEMPLATE_RAG_CONTEXT.md` - Code discovery patterns
- `TEMPLATE_INFRASTRUCTURE.md` - Environment & deployment
- `UNIVERSAL_SETUP_GUIDE.md` - Step-by-step setup instructions

## 🚀 Quick Start

1. **Copy this entire folder** to your new project
2. **Rename folder** from `UNIVERSAL_CONTEXT_TEMPLATE` to `.claude`
3. **Remove `TEMPLATE_` prefix** from all files
4. **Fill out `PROJECT_CONFIG.md`** with your tech stack
5. **Create `PLANNING.md` and `TASK.md`** in project root
6. **Start coding with full context support!**
